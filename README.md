# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/0c0d2889-27b7-4dca-9abc-ca5900ef5c4c

## Run Locally

**Prerequisites:** Node.js (v18 or higher)

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Deploying to GitHub Pages 🚀

This project is fully configured for automated GitHub Pages deployment!

1. **Push your code** to your GitHub repository on the `main` or `master` branch.
2. In your GitHub repository, go to **Settings** -> **Pages**.
3. Under **Build and deployment** -> **Source**, select **GitHub Actions**.
4. The `.github/workflows/deploy.yml` workflow will automatically run on every push to build your Vite app and deploy it to your GitHub Pages URL!
